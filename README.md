# پنل پیامک — Mobile SMS Inbox & Bridge 2.1.3

پل دوطرفه پیامک برای Android و وردپرس شخصی؛ یک برنامه اندروید با دو نقش سرور (گوشی سیم‌کارت‌دار) و کلاینت، و امکان مشاهده صندوق در وب. این نسخه رمزگذاری سرتاسری ندارد؛ مدیر هاست و وردپرس را باید مورد اعتماد دانست.

## دانلود
- [دریافت بسته ZIP نسخه 2.1.3](./sms-bridge-2.1.3-github-ready.zip)
- فایل ZIP را استخراج کنید. تمام مسیرهای زیر مربوط به محتویات همین بسته هستند. فایل APK آماده در بسته وجود ندارد.

## پیش‌نیازها
- وردپرس 6.2 یا جدیدتر، PHP 7.4 یا جدیدتر، OpenSSL، HTTPS معتبر و REST API فعال.
- Android 8.0 یا جدیدتر؛ گوشی سرور باید سیم‌کارت فعال و اینترنت داشته باشد.
- برای ساخت برنامه: Android Studio، JDK 17، Android SDK 35 و اینترنت برای دریافت وابستگی‌ها.

## نصب از ابتدا
1. از وردپرس و پایگاه داده نسخه پشتیبان بگیرید. فایل `dist/sms-bridge-wordpress-2.1.3.zip` را از پیشخوان ← افزونه‌ها ← افزودن ← بارگذاری افزونه نصب و فعال کنید.
2. منوی «پل پیامک» را باز کنید و یک گوشی سرور ایجاد کنید. آدرس سایت و دو کلید مستقل سرور و کلاینت را بردارید.
3. برنامه اندروید را از سورس بسازید: پوشه `android` را در Android Studio باز کنید؛ پس از همگام‌سازی Gradle، در ترمینال پوشه اجرا کنید: `./gradlew assembleDebug` (ویندوز: `gradlew.bat assembleDebug`). خروجی `app/build/outputs/apk/debug/app-debug.apk` است. این فایل را روی گوشی‌های مورد اعتماد نصب کنید؛ فقط برای نصب همین فایل به منبع نصب مجاز Android اجازه بدهید.
4. روی گوشی سیم‌کارت‌دار نقش سرور، آدرس HTTPS سایت خودتان و کلید گوشی سرور را وارد کنید؛ تست اتصال، ذخیره و شروع، سپس رضایت و مجوزهای SMS و اعلان را تأیید کنید. پس از توقف اجباری یا خاموش و روشن شدن، سرویس را بررسی و در صورت نیاز دوباره شروع کنید.
5. روی گوشی دوم نقش کلاینت، همان آدرس و فقط کلید اتصال کلاینت را وارد کنید. می‌توانید در وردپرس نیز صفحه‌ای با shortcode `[sms_bridge_client]` ایجاد کنید یا صندوق را از صفحه مدیریت افزونه ببینید.
6. با یک پیام غیرحساس، دریافت و ارسال را آزمایش کنید و وضعیت تحویل را در دو طرف بررسی کنید.

## نکات امنیتی و عیب‌یابی
- این نرم‌افزار فقط برای سیم‌کارت و دستگاه‌های متعلق به شما یا با رضایت صریح مالک است. کلیدها را منتشر نکنید. پیام‌های بانکی و کدهای ورود را برای آزمایش استفاده نکنید.
- برای خطای اتصال، HTTPS، آدرس کامل وردپرس، REST API، مجوزها و آنلاین بودن سرور را بررسی کنید. اگر ارسال نامعلوم است، قبل از ارسال دوباره وضعیت گوشی را بررسی کنید.
- این نسخه تاریخچه قدیمی گوشی را وارد نمی‌کند. پیام‌های جدید پس از اتصال منتقل می‌شوند؛ ممکن است محدودیت Android مانع ارسال یا دریافت شود.
- آدرس پیش‌فرض اختصاصی و کلید امضای قدیمی از این کپی عمومی حذف شده‌اند. فایل جدید ممکن است با امضای متفاوت به‌روزرسانی APK قدیمی نباشد؛ قبل از تغییر نصب، از داده‌ها پشتیبان بگیرید.
- سورس و ZIP افزونه بررسی ساختاری شده‌اند؛ نسخه عمومی تغییر‌یافته هنوز روی گوشی یا سرور واقعی ساخته و آزمایش نشده است.
- راهنمای تکمیلی: `wordpress/README-FA.md` و `android/README-FA.md`.
